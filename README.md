# STM32-based dell latitude D620 motherbooard graft project
This project aims to add modern features and extra bells and whistles to a vintage laptop motherboard using a commodity microcontroller.

## current planned features:
- gesture sensor for sci-fi waving your hand in front of the screen
- SSD1306 OLED to display system stats and battery level
- support for USB-C charging using the MCU to translate PD capabilities to the Dell 1-wire protocol
